# 로드맵

## 현재 위치

M1·M3·M4·M5.5는 완료됐습니다. M2와 M5는 실사용 가능한 proxy 범위까지 구현됐지만, 무료 공식 원천을 더 직접 연결하는 작업은 남아 있습니다.

## 우선순위

1. **KRX Open API 운영 승인·교차 검증** — 구현된 전 종목 배치 수집의 서비스별 승인, 국내 대표 지수의 Yahoo 의존도 축소
2. **ECB·BOJ·Eurostat 직접 계열** — FRED proxy와 공식 원천의 차이를 카탈로그에 표시
3. **2027 공식 일정 갱신** — 각 기관이 확정 일정을 게시한 뒤에만 추가
4. **KRX 시장폭 운영 적재** — 계산기는 구현 완료, 승인 후 등락종목수·거래대금·쏠림 결과 검증
5. **데이터 품질 규칙** — 단위 변경, 비정상 점프, 장기 결측, revision 폭 알림
6. **M6 브리핑** — 관측일과 근거 링크가 포함된 읽기 전용 일일 요약

## 의도적으로 보류한 범위

- 실시간·틱 데이터와 유료 피드는 무료 원칙 때문에 도입하지 않습니다.
- 외부 공개 인증은 homelab reverse proxy 구성이 정해질 때 선택합니다.
- 주문 실행은 M7의 승인·리스크 통제·감사 요건 전에는 구현하지 않습니다.
- 상관과 연결성을 인과 신호나 자동 매매 신호로 승격하지 않습니다.
