# 로드맵

## 현재 위치

M0~M4와 M5.5와 **M6이 완료**됐습니다. M6의 마지막 절은 과거 시점 재생과 누출 점검이었고, 장치는 섰지만 빈티지 원장이 아직 얕아 답할 수 있는 범위가 좁습니다 — 얼마나 좁은지는 `/data`가 계열마다 보고합니다. M5는 실사용 가능한 proxy 범위까지 구현됐고 무료 공식 원천을 더 직접 연결하는 작업이 남았습니다.

수집은 이제 병목이 아닙니다. KRX Open API가 제공하는 31개 서비스를 전량 승인·수집 중이고, 지표 175개·종목 52,026개가 캐시에 있습니다. 남은 일은 대체로 **가진 것을 더 정직하게 읽는 쪽**입니다.

## 우선순위

1. **M8 계좌·보유 자산 관리** — 계좌 5종과 보유 종목을 기록하고 지표와 나란히 읽기. 새 수집기가 거의 필요 없고(국내 상장 종목은 이미 가격이 붙습니다) M6가 만든 층을 그대로 확장합니다. 설계는 [`../plan/portfolio.md`](../plan/portfolio.md)
2. **M7 백테스트 후속** — 2차까지 끝났고 결과는 부정적입니다. 19년(2007-06~2026-08, 4,970일)으로 넓혀도 `risk_off`는 **그 해 안에서 위험한 날을 고르지 못합니다.** 합산 lift +13.9는 층화하면 무너집니다(연도별 +3.4, 분기별 +0.7, 반기별 −1.0). 남은 것은 `_kospi_trend` 중립 밴드 결정과 사전 등록 전향 평가입니다. [`../tasks/M7.md`](../tasks/M7.md)
3. **설명 층 확장** — 핵심 39개는 계열별 설명을 갖췄지만 나머지 136개는 분류 공통 문구입니다. 브리핑 최상위에 자주 오르는 계열부터 채웁니다
4. **ECB·BOJ·Eurostat 직접 계열** — FRED proxy와 공식 원천의 차이를 카탈로그에 표시
5. **데이터 품질 규칙** — 단위 변경, 비정상 점프, 장기 결측, revision 폭 알림
6. **2027 공식 일정 갱신** — 각 기관이 확정 일정을 게시한 뒤에만 추가

## 의도적으로 보류한 범위

- 실시간·틱 데이터와 유료 피드는 무료 원칙 때문에 도입하지 않습니다.
- 외부 공개 인증은 homelab reverse proxy 구성이 정해질 때 선택합니다.
- 주문 실행은 M7의 승인·리스크 통제·감사 요건 전에는 구현하지 않습니다. M8에서 보유 자산을 다루더라도 매수·매도 조언은 이 게이트 안에 머뭅니다.
- 계좌 잔고와 보유 내역은 공개 저장소에 올리지 않습니다. 이 저장소는 public이고 `data/`만 무시되므로, 사용자 자산 데이터는 DB에만 두고 코드·문서·테스트에 넣지 않습니다.
- 상관과 연결성을 인과 신호나 자동 매매 신호로 승격하지 않습니다.
