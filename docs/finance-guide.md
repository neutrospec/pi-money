# 금융 기초 가이드

> 금융을 배우기 시작하는 사람을 위한 입문서. 우리 시스템의 지표들이 왜 중요한지 이해할 수 있게 돕는다.

## 1. 금융시장이란

금융시장은 **자금이 오가는 시장**이다. 크게 나누면:

- **주식시장**: 기업의 소유권(주식)이 거래되는 시장
- **채권시장**: 정부·기업이 돈을 빌리기 위해 발행하는 채권이 거래되는 시장
- **외환시장**: 서로 다른 통화가 거래되는 시장
- **상품시장**: 금·유가·구리 등 원자재가 거래되는 시장

각 시장은 서로 영향을 주고받는다. 이걸 이해하는 게 투자의 시작이다.

## 2. 주요 지표의 의미

### 금리 (Interest Rate)
- **돈을 빌리는 비용**. 기준금리는 중앙은행이 정한다.
- 금리가 **오르면**: 돈을 빌리기 어려워져 소비·투자가 줄고, 주식은 보통 하락
- 금리가 **내리면**: 돈이 풀려 소비·투자가 늘고, 주식은 보통 상승
- 우리가 추적: 한국 기준금리, 미국 기준금리, ECB, 일본, 영국 금리

### 물가 (Inflation)
- **물건 가격이 오르는 속도**. CPI(소비자물가), PCE, PPI가 대표 지표.
- 물가가 **너무 오르면**: 중앙은행이 금리를 올려 진정시킴 → 시장에 충격
- 우리가 추적: 한국 CPI, 미국 CPI·PCE, 유로존 HICP, 중국 CPI

### 환율 (Exchange Rate)
- **통화 간 교환 비율**. 원/달러, 엔/달러 등.
- 원/달러가 **오르면(원화 약세)**: 수출 기업은 유리, 수입 물가는 상승
- 우리가 추적: 원/달러, 유로/달러, 엔/달러, 위안/달러

### 통화량 (Money Supply)
- **시중에 풀린 돈의 양**. M1(현금+요구불예금), M2(광의 통화) 등.
- 통화량이 늘면 보통 물가 상승 압력, 주식·부동산 자산 가격 상승

### 고용 (Employment)
- **경제의 건강 상태**. 실업률, 비농업 고용(NFP) 등.
- 고용이 강하면: 소비가 늘고 경제 성장 → 그러나 물가 상승 압력도

### 성장 (Growth)
- **경제가 얼마나 커졌는가**. GDP 성장률.
- 성장이 강하면: 기업 이익 증가 → 주식 상승

### 신용 스프레드 (Credit Spread)
- **회사채와 국채의 금리 차이**. 회사가 돈 빌릴 때 국채보다 얼마나 더 주는가.
- 스프레드가 **벌어지면(커지면)**: 기업 부도 위험 증가, 시장 경계
- **위기의 조기 경고 지표** — 주식시장보다 먼저 움직이는 경우가 많음

### 시장 심리 (Market Sentiment)
- **투자자들의 감정 상태**. VIX(공포 지수) 등.
- VIX가 높으면: 시장 공포가 큼

## 3. 중앙은행과 금리 결정

중앙은행(한국은행, 연준, ECB, BOJ, BOE)은 **기준금리**를 정해 경제를 관리한다.

- **금리 인상**: 물가를 잡기 위해 (경제 과열 시)
- **금리 인하**: 경기를 살리기 위해 (경제 침체 시)

주요 회의 일정:
- **FOMC** (미국 연준): 연 8회
- **금통위** (한국은행): 연 8회
- **ECB**: 연 8회
- **BOJ** (일본): 연 8회

이 회의 **전에** 시장은 결과를 예측하고, **발표 순간** 크게 움직인다. 그래서 일정 추적이 중요하다.

## 4. 시장의 상호연관성

금융시장은 서로 연결되어 있다:

- **미국 → 세계**: 미국 금리·주가가 세계 시장을 이끄는 경향 (전이효과)
- **금리 → 주식**: 금리 상승은 주식에 부정적
- **환율 → 수출**: 원화 약세는 수출주에 긍정적
- **유가 → 물가**: 유가 상승은 물가 상승 → 금리 인상 압력
- **신용 스프레드 → 주식**: 스프레드 확대는 위험 신호

## 5. 왜 여러 지표를 함께 봐야 하나

단일 지표만 보면 착각할 수 있다. 예:
- 금리가 낮아도 **물가가 급등**하면 다음에 금리가 오를 것
- 주식이 올라도 **신용 스프레드가 벌어지면** 위험 신호

여러 지표를 **함께** 보아야 전체 그림이 보인다. 이것이 우리 시스템이 여러 지표를 모으는 이유다.

## 6. 투자 시 주의

- **과거는 미래를 보장하지 않는다**: 과거 데이터는 참고일 뿐
- **시장은 예측보다 반응**: 발표 순간의 변동을 이해하는 게 중요
- **분산의 중요성**: 여러 자산·시장에 나누면 위험 감소
- **참고 정보일 뿐**: 모든 데이터는 투자 참고용이며, 최종 판단은 본인의 책임

## 용어 사전

| 용어 | 뜻 |
|------|----|
| CPI | 소비자물가지수 — 생활 물가 상승률 |
| PCE | 개인소비지출 물가 — 연준이 선호하는 물가 지표 |
| PPI | 생산자물가지수 — 기업이 사는 원자재 가격 |
| 기준금리 | 중앙은행이 정하는 대표 금리 |
| 국채 | 정부가 발행하는 채권 |
| 회사채 | 기업이 발행하는 채권 |
| 스프레드 | 두 금리의 차이 |
| NFP | 비농업 고용자수 (미국) |
| VIX | 시장 변동성(공포) 지수 |
| M1, M2 | 통화량 지표 |
| GDP | 국내총생산 — 한 나라의 경제 규모 |
| HICP | 유로존 조화 소비자물가 |
